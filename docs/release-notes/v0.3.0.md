# Content Blueprint v0.3.0

รุ่นเปิดตัวสาธารณะสำหรับ Windows 10/11 แบบ 64-bit

## งานที่ทำได้ในรุ่นนี้

- สร้าง Facebook Content Pack 9 ส่วนจาก Brief และ Evidence Notes
- ใช้ Growth Playbook 10 แบบ พร้อม Lead Cards, Commission, UTM และ Experiment Log
- สร้าง ตรวจ และ export บทความใน SEO Workspace
- เลือก Claude Code หรือ Codex CLI ที่ล็อกอินอยู่แล้ว โดยไม่ใส่ API key เพิ่มใน Content Blueprint
- เลือก Quick draft หรือ AI Team แบบ Strategist → Producer/Copywriter → Reviewer
- ดู worker เดิน นั่ง และส่งแฟ้มใน AI Studio ตาม stage events จริง
- เรียนผ่าน Joyride ภาษาไทย 8 ภารกิจ
- เปิด Content/Growth Pack ใน Chrome/Brave side panel ผ่าน Native Messaging
- เปิด Claude/Codex เองแล้วแลกงานกับ companion ผ่าน MCP 7 tools
- ตรวจ update จาก GitHub Releases และติดตั้งเมื่อผู้ใช้ยืนยัน

## ติดตั้ง

ดาวน์โหลด:

- `content-blueprint-amd64-installer.exe`
- `SHA256SUMS.txt`

ตรวจ SHA-256 ของ installer ให้ตรงกับ checksum ก่อนเปิด ตัวติดตั้งลงแบบ per-user ใต้ `%LOCALAPPDATA%\Programs\Content Blueprint` และลงทะเบียน Native Messaging สำหรับ Chrome/Brave

Browser extension ยังต้องเปิด Developer mode และ Load unpacked จากโฟลเดอร์ที่ติดตั้ง เพราะรุ่นนี้ไม่ได้เผยแพร่ผ่าน Chrome Web Store

## ข้อควรรู้ก่อนใช้

- Executable และ installer ยังไม่ได้เซ็น Windows Authenticode จึงอาจเจอ SmartScreen
- แอปไม่ scrape Facebook, ไม่เก็บฐานลูกค้าจากเพจอื่น, ไม่ส่งข้อความ และไม่กดเผยแพร่
- AI output ไม่รับประกันข้อเท็จจริง กฎหมาย ยอดขาย reach หรือ conversion
- Claude/Codex route ใช้ quota, rate limit และข้อกำหนดของบัญชี CLI ที่ล็อกอินอยู่
- Local JSON stores ไม่ได้เข้ารหัสที่ระดับแอป
- Updater ตรวจ SHA-256 แต่ checksum ใน release เดียวกันไม่ใช่หลักฐาน publisher identity แบบ code signing

## ตรวจไฟล์

```powershell
Get-FileHash .\content-blueprint-amd64-installer.exe -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```
